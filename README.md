# 备考工作台 📚

一个功能完整的网页版备考工作台，单文件 HTML，无需安装，浏览器打开即用。手机、电脑多端自适应。

## ✨ 核心功能

- **📝 刷题中心**：三栏布局（题库列表 / 刷题区 / 统计），支持选择题、填空题，答对/答错即时判题回显解析，错题自动收纳
- **❌ 错题库**：记录错题原因、解题步骤、个人技巧，一键加入下周计划，自动纳入遗忘曲线
- **🤖 AI 自动提炼知识点**：导入教材 / PPT / PDF 后，调用大模型自动抽取章节知识点与题目，预览后并入题库
- **🔁 艾宾浩斯复习**：按 1/2/4/7/15/30 天自动排程复习，答对升级、忘记退回
- **🎯 考点掌握度**：按科目统计正确率、薄弱项分析，一键加入复习任务
- **🃏 知识闪卡**：正反面翻转、填空自测
- **📁 资料库**：PDF / TXT / Word 导入、图片型 PDF 自动 OCR、视频资料归档管理
- **🍅 番茄钟**：专注计时计入学习台账
- **📈 备考总进度 / 数据看板 / 周月复盘**

## 🚀 使用

直接用浏览器打开 `index.html` 即可（数据保存在浏览器本地 localStorage，可导出 / 导入 JSON 备份）。

部署到 GitHub Pages 后，直接用网址访问。

## 🛠 本地 / AI 联网说明

- 核心刷题、错题、闪卡、复习计划、掌握度**完全离线可用**，无需联网。
- **AI 提炼**需要配置大模型 API。若所用 API（如 sensnova）不支持浏览器直连（会报 CORS），需在本地运行 `AI中转代理.py` 中转（见文件头说明），工作台地址填 `http://127.0.0.1:8787/v1`。
- 图片型 PDF 的 OCR 识别依赖浏览器联网加载 PDF.js / tesseract.js。
